About the project

Explainable classification,
without pretending to know the truth.

Signal Check is an educational machine-learning prototype that demonstrates how TF-IDF and Logistic Regression can classify news text through a lightweight Flask application.

Method

How the model was built

01Source integrity

The WELFake source file was verified before analysis and retained unchanged.

02Deterministic preparation

Normalised duplicate title/body pairs were removed before stratified splitting.

03Feature comparison

Headline-only, article-only, and combined inputs were evaluated on validation data.

04Final evaluation

The combined model was evaluated once against the untouched held-out test split.

Final model

TF-IDF + Logistic Regression

Features
100,000 maximum
N-grams
Unigrams + bigrams
Test accuracy
96.42%

96.39%
Limitation

Classification is not verification

The model detects patterns associated with its training labels. It does not consult primary sources, establish events, or prove that a claim is true or false.
